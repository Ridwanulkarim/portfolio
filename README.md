# Mohammad Ridwanul Karim — Developer Portfolio

Production-ready personal developer portfolio website for **Mohammad Ridwanul Karim (Ridwan)**, Computer Science & Engineering student, Frontend Developer, Full-Stack Development Enthusiast, and AI/ML Enthusiast.

Built with **React, Vite, Tailwind CSS, Framer Motion, and React Icons**.

## 🌐 Live Website

- **Live Demo**: [https://ridwanulkarim.netlify.app](https://ridwanulkarim.netlify.app/)

---

## 🚀 Tech Stack

- **Framework**: React + Vite
- **Styling**: Tailwind CSS (v4) + Vanilla CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Typography**: Google Fonts (Inter, Space Grotesk, Manrope)

## 🛠 Getting Started Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
